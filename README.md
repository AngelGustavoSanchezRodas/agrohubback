# 🌾 AgroHub Backend - API AgroIoT (Invernaderos)

Backend desarrollado con **FastAPI** para la ingesta, procesamiento y persistencia de telemetría proveniente de dispositivos IoT (ESP32) instalados en invernaderos.

El sistema implementa una persistencia dual:
- **Firebase Realtime Database:** Almacenamiento del estado actual en tiempo real para visualización inmediata en paneles o aplicaciones móviles.
- **Supabase (PostgreSQL):** Almacenamiento histórico de lecturas para auditoría, gráficas temporales y análisis de datos.

---

## 📋 Requisitos Previos

Asegúrate de contar con las siguientes herramientas instaladas en tu equipo:

- **Python 3.10+** (Recomendado Python 3.12 o superior)
- **Git**
- **Cuenta y proyecto en Firebase** (con servicio de Realtime Database habilitado)
- **Cuenta y proyecto en Supabase** (con base de datos PostgreSQL)

---

## 🚀 Instalación y Puesta en Marcha

Sigue estos pasos en orden para clonar el repositorio, configurar el entorno e iniciar el servidor.

### 1. Clonar el Repositorio

Abre una terminal y ejecuta el siguiente comando:

```bash
git clone <URL_DEL_REPOSITORIO>
cd AgroHubBack
```

*(Reemplaza `<URL_DEL_REPOSITORIO>` por el enlace Git correspondiente a tu repositorio).*

---

### 2. Crear y Activar un Entorno Virtual

Es recomendable utilizar un entorno virtual para aislar las dependencias del proyecto.

#### En Windows:
```powershell
# Crear el entorno virtual
python -m venv .venv

# Activar el entorno en PowerShell
.\.venv\Scripts\Activate.ps1

# O si utilizas CMD (Símbolo del sistema):
.\.venv\Scripts\activate.bat
```

> **Nota para PowerShell:** Si recibes un error indicando que la ejecución de scripts está deshabilitada en tu sistema, ejecuta una vez en PowerShell con permisos de administrador:
> ```powershell
> Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
> ```

#### En Linux / macOS:
```bash
# Crear el entorno virtual
python3 -m venv .venv

# Activar el entorno
source .venv/bin/activate
```

---

### 3. Instalar Dependencias

Con el entorno virtual activado, actualiza `pip` e instala las librerías necesarias:

```bash
python -m pip install --upgrade pip
pip install -r requirements.txt
```

Las dependencias principales instaladas son:
- `fastapi`: Framework web moderno y de alto rendimiento para construir APIs.
- `uvicorn`: Servidor ASGI para ejecutar la aplicación FastAPI.
- `firebase-admin`: SDK oficial para la interacción con Firebase (Realtime Database / Firestore).
- `supabase`: Cliente oficial para interactuar con bases de datos y servicios de Supabase.
- `python-dotenv`: Manejo de variables de entorno desde archivos `.env`.

---

### 4. Configurar Variables de Entorno y Credenciales

El proyecto requiere claves y credenciales de acceso para conectarse a Firebase y Supabase.

#### A. Archivo de Variables de Entorno (`.env`)
Crea una copia del archivo `.env.example` y nómbrala `.env`:

- **Windows:**
  ```powershell
  copy .env.example .env
  ```
- **Linux / macOS:**
  ```bash
  cp .env.example .env
  ```

Edita el archivo `.env` generado con tus credenciales:

```ini
# Configuración de Firebase
FIREBASE_CREDENTIALS=firebase-credentials.json
FIREBASE_URL=https://<tu-proyecto>-default-rtdb.firebaseio.com/

# Configuración de Supabase
SUPABASE_URL=https://<tu-id-proyecto>.supabase.co
SUPABASE_KEY=tu_supabase_api_key_o_secret
```

#### B. Credenciales de Firebase (`firebase-credentials.json`)
1. Ve a la consola de Firebase: **Configuración del proyecto** > **Cuentas de servicio**.
2. Haz clic en **Generar nueva clave privada**.
3. Descarga el archivo JSON y colócalo en la raíz del proyecto con el nombre:
   ```
   firebase-credentials.json
   ```

> ⚠️ **Importante:** Por seguridad, tanto el archivo `.env` como `firebase-credentials.json` están incluidos en el `.gitignore` y **nunca** deben subirse a repositorios públicos o remotos.

---

### 5. Estructura de la Base de Datos (Supabase)

Asegúrate de que la tabla `telemetria_historica` exista en tu base de datos de Supabase. Si aún no la has creado, puedes ejecutar la siguiente consulta en el **SQL Editor** de Supabase:

```sql
create table if not exists telemetria_historica (
    id bigint generated by default as identity primary key,
    created_at timestamp with time zone default timezone('utc'::text, now()) not null,
    id_dispositivo text not null,
    temperatura double precision,
    humedad_ambiente double precision,
    humedad_suelo double precision,
    radiacion_solar integer,
    luz_uv integer
);
```

---

### 6. Ejecutar la Aplicación

Inicia el servidor de desarrollo utilizando `uvicorn`:

```bash
uvicorn main:app --reload
```

Si necesitas permitir conexiones desde dispositivos en la misma red local (por ejemplo, el ESP32):

```bash
uvicorn main:app --reload --host 0.0.0.0 --port 8000
```

- **API Base:** `http://localhost:8000`
- **Documentación Interactiva (Swagger UI):** `http://localhost:8000/docs`
- **Documentación Alternativa (Redoc):** `http://localhost:8000/redoc`

## 📡 Endpoints de la API

### Ingesta de Telemetría ESP32

- **Método:** `POST`
- **Ruta:** `/api/telemetria`
- **Cabeceras:** `Content-Type: application/json`

#### Cuerpo de la petición (JSON):
```json
{
  "id_dispositivo": "ESP32_INV_01",
  "temperatura": 24.5,
  "humedad_ambiente": 65.0,
  "humedad_suelo": 45.2,
  "radiacion_solar": 850,
  "luz_uv": 3
}
```

#### Respuesta exitosa (`200 OK`):
```json
{
  "mensaje": "Datos guardados en Firebase y Supabase",
  "status": "ok"
}
```

#### Ejemplo de prueba con cURL:
```bash
curl -X POST "http://localhost:8000/api/telemetria" \
     -H "Content-Type: application/json" \
     -d '{
       "id_dispositivo": "ESP32_INV_01",
       "temperatura": 24.5,
       "humedad_ambiente": 65.0,
       "humedad_suelo": 45.2,
       "radiacion_solar": 850,
       "luz_uv": 3
     }'
```
